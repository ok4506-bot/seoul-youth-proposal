# 서울은 청년이 들어오는데도 왜 늙어가는가 — Project Proposal

청년이 들어오는 작은 집과 30대에 떠나는 길을 따라, 서울이 청년에게 '거쳐 가는 도시'가 되는 과정을 보려는 프로젝트 제안 발표 자료입니다.

- 들어오는 쪽: 서울의 청년은 어떤 작은 집에 모이는가
- 나가는 쪽: 30대 가구는 왜, 어디로 떠나며, 그곳은 어떤 곳인가

`index.html` 한 파일로 된 발표 자료(17장)입니다. 브라우저로 열면 바로 볼 수 있습니다.

## 조작

| 키 | 동작 |
| --- | --- |
| ← / → | 이전 / 다음 장 |
| N | 발표 메모 |
| F | 전체 화면 |
| P | 인쇄 |

## 자료

행정안전부 주민등록 인구(행정동), 통계청 MDIS 국내인구이동통계, SGIS 1km 격자 인구, KOSIS 인구총조사, 건축물대장, UPIS 용도지역, 서울시 전월세 실거래. 수치는 파일럿 분석 결과이며 최종 결과가 아닙니다.

## 배포

빌드 과정이 없는 정적 페이지입니다. Cloudflare Pages에서 이 저장소를 연결하고 빌드 명령은 비워 두며, 출력 디렉터리는 `/`로 둡니다.
